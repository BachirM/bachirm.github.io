# Portfolio de Bachir Mbacke

Site statique en HTML, CSS et JavaScript, prêt pour GitHub Pages.

## Prévisualiser
Ouvrir `index.html` dans un navigateur. Une connexion internet est nécessaire pour charger les polices Google Fonts ; le reste du site fonctionne localement.

## Publier sur GitHub Pages
1. Créer un dépôt GitHub (par exemple `bachir-portfolio`).
2. Ajouter à la racine tous les fichiers du dossier.
3. Dans GitHub, ouvrir **Settings → Pages**.
4. Choisir **Deploy from a branch**, sélectionner `main` et le dossier `/ (root)`, puis enregistrer.
