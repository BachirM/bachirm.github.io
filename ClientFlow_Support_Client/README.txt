CLIENTFLOW — ESPACE SUPPORT CLIENT
=================================

Ouverture :
1. Décompressez le dossier.
2. Ouvrez index.html dans un navigateur récent.

Fonctions :
- Répertoire de contacts clients (exemples fictifs).
- Journal des interactions : téléphone, e-mail, chat, accueil, courrier.
- Catégorisation : information, demande administrative, réclamation, assistance, suivi.
- Suivis à effectuer et cases à cocher.
- Réponses types à copier et adapter.

Important :
Cette application est un prototype pédagogique front-end. Les données sont fictives.
Elle fonctionne localement dans le navigateur, sans serveur, sans compte, sans connexion
à un CRM ou à un système professionnel. Ne saisissez aucune donnée réelle de client.
Les données créées ne sont pas garanties d'être conservées après fermeture/rechargement.
